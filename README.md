# KH2-Vanilla-Seed

I made this :) to use for vanilla bingo with the Garden of Assemblage mod (Normal and Reverse).

- Start with Scan, Guard, Aerial Recovery, Dodge Roll level 1
  - Vanilla locations of these abilities are replaced with potions
    - Station of Serenity bonus
    - Twilight Thorn bonus
    - Axel 1 bonus
    - Limit Form level 3
- Start with Unknown Disk for free Cosmic Chain in Heartless Manufactory
- Faster Drive Form EXP multipliers
  - Valor x5
  - Wisdom x3
  - Limit x2
  - Master x2
  - Final x3
- When used with the GoA mod:
  - Roxas can't use movement or magic
  - Can skip forced job in STT
  - STT Day 5 skip is active
  - Munny pouches give 5000 munny
  - Moogle Shops aren't vanilla. They have items and Donald/Goofy weapons
